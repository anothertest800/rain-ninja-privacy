# Rain Ninja privacy policy

This repository holds the privacy policy of **Rain Ninja**, a motorcycle ride planner with live rain radar for Android.

- Read it here: **https://anothertest800.github.io/rain-ninja-privacy/**
- The same text is inside the app: Settings, at the bottom, "Privacy policy".
- The file is [`index.html`](index.html). The page in the app is the same file, byte for byte.

## Questions and requests

Open an issue: https://github.com/anothertest800/rain-ninja-privacy/issues

This page is public. Please do not write personal details in an issue.
